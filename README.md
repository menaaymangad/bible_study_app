# Bible School

Bible School is a Flutter app for classroom and personal Bible study.

This repository is a **distribution-only** repository. It hosts app releases
and download links; it does not contain application source code or
development history. Source is maintained in a private repository.

## Download

Latest APK (always up to date):

**[Download BibleSchool.apk](https://github.com/menaaymangad/bible_study_app/releases/latest/download/BibleSchool.apk)**

Or grab a specific version from the [Releases](https://github.com/menaaymangad/bible_study_app/releases) page.

### Installing on Android

1. Download `BibleSchool.apk` using the link above.
2. If prompted, allow installation from this source in your device settings.
3. Open the downloaded file to install.
